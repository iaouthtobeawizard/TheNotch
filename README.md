# TheNotch

A lightweight Dynamic Island-style notch for Wayland, built with Quickshell, QML and Rust.

## Features

- Time
- Date
- Battery status
- Battery charging indicator
- Audio visualizer
- Configurable notch
- Theme support
- Wayland exclusive zone

## Requirements

- Wayland
- Quickshell
- Rust
- PipeWire
- Nerd Font

## Installation

```bash
git clone https://github.com/iaouthtobeawizard/TheNotch.git
cd TheNotch
./install.sh
```

## Starting Notch

```bash
notch-qs
```
